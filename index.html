Topics Covered

1. Introduction to Data Communication

Data communication is the exchange of data between devices through a transmission medium such as cables, fiber optics, or wireless signals. It involves components like sender, receiver, message, transmission medium, and protocols. The main goal is to transfer information accurately and efficiently.

2. Networking Fundamentals

Networking fundamentals explain how computers and devices connect and communicate. Key concepts include:

  • Types of networks: LAN, MAN, WAN
  • Network topologies: star, bus, ring, mesh
  • Network devices: routers, switches, hubs, modems
  • Communication protocols used for data exchange
3. Network Reference Models

This topic introduces models that standardize communication processes.

OSI Model
  • Physical Layer
  • Data Link Layer
  • Network Layer
  • Transport Layer
  • Session Layer
  • Presentation Layer
  • Application Layer
TCP/IP Model
  • Network Access Layer
  • Internet Layer
  • Transport Layer
  • Application Layer
4. Transmission Media

Transmission media are the channels used to carry data signals.

Guided Media
  • Twisted pair cables
  • Coaxial cables
  • Fiber optic cables
Unguided Media
  • Radio waves
  • Microwaves
  • Infrared communication
5. Signals

Signals are electrical or electromagnetic representations of data.

Analog Signals

Continuous signals that vary smoothly over time.

Digital Signals

Discrete signals represented by binary values (0s and 1s).

Key concepts: frequency, amplitude, bandwidth, attenuation, noise and interference.

6. Wireless Networks & Technologies

Wireless communication allows devices to connect without physical cables.

  • Wi-Fi
  • Bluetooth
  • Cellular networks (4G/5G)
  • Satellite communication

Advantages: Mobility, easy installation, flexibility.

Challenges: Security risks, signal interference, limited coverage.

7. CIA Triad & Cryptography

The CIA Triad is the foundation of information security.

  • Confidentiality: Protecting from unauthorized access.
  • Integrity: Ensuring data remains accurate and unaltered.
  • Availability: Ensuring systems are accessible when needed.

Cryptography protects data using symmetric encryption, asymmetric encryption, and hashing.

8. Data & Network Security

Methods used to protect computer systems and networks from attacks.

Data Security

Protects stored and transmitted data.

Network Security

Protects network infrastructure using firewalls, intrusion detection systems, and antivirus software.

Cybersecurity

Defends systems against hacking, malware, phishing, and ransomware.

9. Data Protection Policies & Acts

Laws and regulations that govern data privacy and protection.

  • User privacy rights
  • Ethical handling of data
  • Legal responsibilities of organizations
  • Data protection standards (e.g. GDPR)
